The raw spans above come from `POSITION` accessor min/max values. They are source-space metadata, not transformed world dimensions: node transforms, exported roots, rotations, and the runtime bounding-box normalization can materially change the usable size. `ModelAsset` currently normalizes vehicle models by bounds, so each vehicle still requires an explicit target length/height and rotation decision.

## Acceptance status

Acceptance is pending user visual review. No asset has been visually inspected in the running game, and no claim is made that the models match the approved Kerala circa-2000 art direction. Confirm placement, color treatment, collision footprint, and building/ground extraction with screenshots before calling any asset ready.

## Required optimization and extraction pass

1. For `amusement_park.glb`, inspect the scene hierarchy, identify the actual park root and intended rides/buildings, remove export debris and unrelated nodes, then generate a bounded placement wrapper. Keep the big Silver Storm pool as a separately authored water surface so its footprint and collision are controlled.
2. For `low_poly_fuel_station.glb`, isolate the station canopy, pumps, signs, and selected props; exclude duplicate cars and the asphalt presentation plane unless the world layout explicitly needs it. Preserve attached structural slabs or verandas. Normalize the extracted group before placement.
3. For `coffee_shop_isometric.glb`, retain the building shell, attached structural slab/veranda, and requested exterior identity while filtering presentation planes and interior-only furniture from the world prop.
4. For cars, add model IDs and per-model target dimensions/rotation, then map only verified wheel nodes. Treat Bronco tire motion as unresolved until geometry can be separated or a derived asset is produced.
5. Recheck draw-call/triangle cost after extraction, especially for the 31 MB park and 24.63 MB fuel station, and use distance-based loading or reduced variants if the running UI shows frame cost.

No production files were changed and no tests were run for this intake.
